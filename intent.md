# Intent

Swarmer Finance — инструмент учёта капитала (wealth management), а не
бюджета: главный вопрос — «сколько у меня всего и как это меняется».
Учёт денег (транзакции, категории, импорт выписок, синхронизация банков и
кошельков) реализован; дальше — капитал.

## Функции из похожих приложений

Обзор 2026-10-28: Kubera, Ghostfolio, Finary, Getquin, Sharesight,
Wealthfolio, Empower, ProjectionLab; для бюджета — YNAB, Monarch, Actual
Budget, Firefly III, Lunch Money, Zenmoney, CoinKeeper, Toshl.
Статус: **в работе** / **позже** / **не нужно сейчас**.

### Капитал
- **в работе** — История капитала: итог в базовой валюте по месяцам, график
  (все приложения учёта капитала).
- **в работе** — Активы без транзакций с ручной оценкой: недвижимость,
  брокерский счёт, вклады/облигации (Kubera).
- **в работе** — Разбивка по видам активов и валютам; валютный риск.
- **в работе** — Выбор, какие счета входят в капитал (личная настройка).
- **в работе** — Простая доходность счёта: вложено vs стоит (Kubera, Finary).
- позже — Долги: кредиты, ипотека, график погашения (Kubera, Monarch).
- позже — Целевое распределение активов и подсказки по ребалансировке
  (Ghostfolio, Wealthfolio).
- позже — Разбивка по странам/секторам (Ghostfolio, Getquin).

### Инвестиционный портфель
- позже — Позиции по тикерам, количество, цена покупки (Ghostfolio,
  Sharesight, Wealthfolio).
- позже — Автоматические котировки акций/ETF.
- позже — Доходность XIRR / TWR, сравнение с бенчмарком (Sharesight,
  Ghostfolio).
- позже — Дивиденды и купоны, календарь выплат (Getquin, Sharesight).
- позже — Импорт сделок из брокера: IBKR Flex, CSV (Sharesight, Ghostfolio).
- позже — Реализованная/нереализованная прибыль, учёт по партиям (FIFO),
  налоговые отчёты (Sharesight).
- позже — Расширение крипты: токены, стейкинг, другие сети, DeFi-позиции
  (Finary, Kubera).

### Планирование
- позже — Прогноз капитала по норме сбережений и доходности, дата FIRE
  (ProjectionLab, Finary).
- позже — Цели накоплений с прогрессом (Monarch, YNAB).
- позже — Сценарии «что если» (ProjectionLab).

### Безопасность и доступ
- позже — «Наследник» / dead man's switch: доступ доверенному лицу после
  долгого отсутствия (Kubera); ложится на существующие account_shares.
- позже — Двухфакторная аутентификация.
- позже — Экспорт всех данных (CSV/JSON).

### Бюджет и траты (не основной фокус)
- не нужно сейчас — Бюджеты по категориям / envelope budgeting (YNAB,
  Actual).
- не нужно сейчас — Регулярные платежи и подписки, напоминания (Monarch,
  Lunch Money).
- не нужно сейчас — Правила автокатегоризации (Firefly III, Lunch Money).
- не нужно сейчас — Теги, вложения (чеки), сплит транзакций (Firefly III).
- не нужно сейчас — Отчёты: доходы/расходы по месяцам, cash flow, норма
  сбережений (Monarch, Firefly III).
- не нужно сейчас — Мобильное приложение / PWA, быстрый ввод (Zenmoney,
